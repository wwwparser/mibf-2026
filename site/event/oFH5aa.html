Пушистые малыши: рисуем восковыми мелками

чт, 3 сентября, 13:00–14:45 · Дети. Мастерская

Мастер-классПРОГРАММА ДЛЯ ДЕТЕЙ

Приходите творчески хулиганить в смешанной технике! На занятии ребята научатся работать с восковыми мелками, откроют для себя приём растушёвки ватными палочками и унесут домой очаровательную поделку: разноцветных пушистых птенцов на ветке под ласковым солнышком. Техника специально подобрана так, чтобы результат радовал с первых минут. Мастер‑класс идеально подходит для первого знакомства с художественными приёмами — он развивает мелкую моторику, чувство цвета и даёт ребёнку свободу для творчества: можно менять оттенки, добавлять детали и придумывать свой сюжет.
