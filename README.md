# ММКЯ-2026 — разбор ярмарки

**Сайт: https://wwwparser.github.io/mibf-2026/**

Статический сайт-разбор 39-й Московской международной книжной ярмарки
(2–6 сентября 2026, «Гостиный Двор»). Вся фактура собирается скриптами
из открытых источников, сайт генерится в папку `site/` и кладётся на
GitHub Pages как есть — бэкенда нет.

## Что внутри сайта

## Откуда данные

**Открытое API сайта программы** — `events.mibf.info`. Найдено разбором
JS-бандла Nuxt-приложения:

```
GET /2026/api/locations       площадки + 243 участника со стендами
GET /2026/api/events          509 событий (кратко)
GET /2026/api/events/<id>     карточка события: описание, спикеры, организаторы
GET /2026/api/exhibitors/<id> карточка участника: описание, сайт, почта, телефон, адрес
```

Ключей не требует, но **без заголовка `Referer` с домена events.mibf.info
отдаёт `401 Access Denied`** — это единственная защита.

**Пресс-релиз** — PDF с Яндекс.Диска организаторов, забирается через
`cloud-api.yandex.net/v1/disk/public/resources/download`.

**«Библиотека» Радио РБК** — RSS подкаста на mave.digital, адрес находится
через поиск Apple Podcasts. На biblio.rbc.ru названия выпусков — картинки,
текстом их там нет.

**Соцсети спикеров, лекции на YouTube, ссылки на книги** — поисковая выдача
через [XMLRiver](https://xmlriver.com) (один платный запрос на имя/книгу).

**Классификация** (что из найденного в кавычках действительно книга, к какому
типу относится участник, кто назван в пресс-релизе) — бесплатные модели
OpenRouter.

**Соцсети и почты участников** — скилл `contact-scraper` обходит сайт каждого
участника («главная» + «контакты/о нас») и добирает Telegram, MAX, VK, WhatsApp
и дополнительные адреса; карта ярмарки даёт только почту и телефон.

**Посты телеграм-каналов участников** — Telegram API на общей сессии скилла
`telegram-chat-analysis`. Проверено 6 сентября 2026: с этой машины MTProto
проходит напрямую, локальный SOCKS5 не понадобился.

**Записи трансляций VK** — список принимается текстом: `vkvideo.ru/@mmkya/all`
отдаётся только авторизованным (без входа — редирект на `errorCode=11300`).
Скрипт сам сопоставляет ролики с событиями программы по названию.

## Как собрать

```bash
pip install -r requirements.txt
cp .env.example .env        # вписать ключи XMLRiver и OpenRouter

python scripts/fetch_all.py                    # программа, участники, спикеры   (~4 мин)
python scripts/fetch_exhibitors.py             # карточки участников с карты
python scripts/group_exhibitors.py             # типы организаций (LLM)
python scripts/extract_books.py                # сквозной список книг            (~3 мин)
python scripts/extract_press_people.py         # люди из пресс-релиза (LLM)
python scripts/fetch_rbc_biblio.py             # выпуски подкаста «Библиотека» РБК

# контакты участников: обход сайтов скиллом contact-scraper -> сведение -> телеграм
S=~/.claude/skills/contact-scraper/scripts/scrape_contacts.py
python $S --excel data/contacts/exhibitors_sites.xlsx \
    --site-col Сайт --name-col Компания \
    --outdir data/contacts/out --intl --resume
python scripts/merge_contacts.py               # соцсети и почты -> exhibitors.json
python scripts/fetch_tg_posts.py --days 10     # посты каналов участников
python scripts/import_vk_videos.py data/vk/vkvideo_mmkya_all.txt

# платные шаги (XMLRiver)
python scripts/enrich_books.py  --limit 400                # магазины
python scripts/enrich_books.py  --limit 400 --mdk-pass     # добить «Дом книги»
python scripts/enrich_books.py  --limit 400 --wide-pass    # издательства и прочие магазины
python scripts/enrich_people.py --limit 1200               # соцсети
python scripts/enrich_youtube.py --limit 1200              # лекции на YouTube
python scripts/research_topic.py --preset services         # фактура под статьи

python scripts/build_site.py                   # собрать site/
```

Все шаги умеют resume: повторный запуск не перезапрашивает уже собранное.
Сайт собирается и без платных шагов — страницы книг и спикеров просто будут
без внешних ссылок.

### Сколько стоят платные шаги

XMLRiver считает один платный запрос за пару «запрос × страница выдачи».
Мы берём топ-10, то есть один запрос на книгу и один на человека:

```
368 книг × 3 прохода + 1195 человек × 2 (соцсети + YouTube) ≈ 3500 платных запросов
```

Если на счету кончаются деньги, клиент бросает `QuotaExhausted`, прогон
останавливается и сохраняет собранное — доливать баланс и запускать заново.

## Как добавить статью

Положить файл в `content/articles/`, первым блоком — метаданные:

```html
<!--meta
title: Заголовок статьи
lead: Одно предложение для карточки на хабе.
tag: Индустрия
-->
<h1>…</h1>
```

Пересобрать сайт — статья появится в `articles.html` и в меню.

## Публикация на GitHub Pages

Сайт живёт в ветке `gh-pages` (там лежит содержимое `site/`), исходники — в `main`.
Pages настроены на `gh-pages` → корень. После пересборки:

```bash
python scripts/build_site.py
git add -A && git commit -m "Обновить данные"
git push origin main
git subtree push --prefix site origin gh-pages     # выложить сайт
```

Если `subtree push` откажется из-за расхождения истории:

```bash
git push origin `git subtree split --prefix site main`:gh-pages --force
```

Файл `site/.nojekyll` обязателен — иначе Jekyll на стороне GitHub пропускает
папки, начинающиеся с подчёркивания, и часть файлов не публикуется.

## Ссылки VK и https

Плеер VK встраивается только на защищённые страницы: с `http://127.0.0.1`
`video_ext.php` показывает «Видео недоступно», с https тот же код играет
(проверено 6 сентября 2026). Поэтому при локальном просмотре клик по превью
открывает запись во ВКонтакте, а на опубликованном сайте — играет на месте.

## Оговорки

- Это независимый разбор, не официальный сайт ярмарки.
- Тексты `press.html`, `stroki.html` и статей написаны вручную; данные и таблицы
  генерятся из выгрузок.
- Почты, телефоны и соцсети участников выводятся на странице участников: это
  те же контакты, что организаторы публикуют на официальной карте ярмарки,
  плюс ссылки с сайтов самих компаний. Использовать их для спама нельзя.
- В разборе телеграма только публичные каналы организаций-участников;
  личные переписки и закрытые чаты не затрагиваются.
- Ссылки на соцсети и книги найдены автоматически поиском: возможны однофамильцы
  и однотитульники, особенно у коротких названий вроде «Гамлет».
- Названия участников в официальном SVG-мастерплане переведены в кривые,
  текстом оттуда они не читаются — список берётся из API.
